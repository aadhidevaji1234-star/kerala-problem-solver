KERALA PROBLEM SOLVER 3000 — Malayali reaction audio
====================================================

Drop your OWN recorded / royalty-free meme audio clips here.
Do NOT add copyrighted audio.

Expected filenames (mp3, ~1-2 seconds each):

  enthokkeya.mp3   -> "Enthokkeya ee kaanikkunne?"
  ayyoo.mp3        -> "Ayyoo!"
  daivame.mp3      -> "Daivame..."
  nee-poda.mp3     -> "Nee poda!"
  oru-rakshayum.mp3-> "Oru rakshayum illa."
  adipoli.mp3      -> "Adipoli!"
  enthuvaade.mp3   -> "Enthuvaade?"
  blip.mp3         -> generic UI click/whoosh sound

If a file is missing, the app falls back to a synthesized beep and still
shows the reaction text on screen. Nothing breaks.
